What it monitors

Built on LibreHardwareMonitor, the open-source sensor library behind many Windows monitoring tools. Every row has a tooltip that explains it in one plain sentence.

CPU

Load per core or thread, package and core temperatures, clocks, Vcore, RAPL power and headroom to TjMax. Intel P-cores and E-cores are shown apart.

GPU

Discrete NVIDIA and AMD cards and Intel integrated graphics: load, core, hot spot and memory junction temperatures, clocks, encoder load, fan, power and VRAM.

Memory

Used, cached and pagefile, plus per-module DIMM temperatures where the modules report them, with vendor, part number and timings on hover.

Storage

Temperature against each drive's own limits, activity, capacity and health, and SMART lifetime on hover: power-on hours, NVMe wear and data written.

Board, fans and power

Motherboard and VRM temperatures, fan speeds and voltage rails, battery charge rate and health, and the board model and BIOS version.

Network and themes

Throughput and link use, with SSID and signal on Wi-Fi. Six themes, from CRT amber to a plain light one, can follow Windows' light and dark setting.

The window

Cards scale to fill any window, from 720×500 up to a 4K screen, with no scroll bar; the least important readings step aside first. Backgrounds can be made see-through from 100 % down to 30 %, and the window collapses into a one-line strip of live values that sits over the top of the screen without taking any of it.

How it works

Two programs, one installer: a dashboard that runs as you, and a sensor service that runs only while the dashboard is open.

  1. A dashboard that runs as you

    PerfWindow.exe is a Rust and egui app without administrator rights. It draws the cards and talks to the sensor service over a named pipe.

  2. A sensor service on demand

    Reading CPU registers and drive SMART data needs administrator rights, so a .NET service built on LibreHardwareMonitor does it. Windows asks once per launch to start it.

  3. First readings in about a second

    The service opens the CPU and memory sensors first, then the board, GPU, drives, network and battery, while the loading screen shows its progress.

  4. Gone when you close it

    The service exits as soon as the dashboard disconnects. No tray icon, nothing at startup, and the uninstaller removes every file and your settings.

Tested, and honest about limits

How it's verified

  • 346 Rust tests for the dashboard and 112 .NET tests for the sensor service run on every push to main and every pull request.
  • Clippy with warnings as errors, format checks and a cargo audit of every Rust dependency.
  • CI then builds the full installer, with the license texts of every bundled component.

What it can't do

  • Read what the hardware hides. What appears depends on the board, chips and drivers, and some machines report only part of it.
  • Change anything. It reads sensors only: no overclocking, undervolting or fan control.
  • Skip the prompt. Admin-only sensors need one approval per launch. The installer isn't code-signed yet, so SmartScreen warns.
  • Move the strip by itself. The mini strip stays on the monitor it was last on and covers its top edge; if that monitor goes away it moves to the one the window is on.

Questions

Is PerfWindow free?

Yes. PerfWindow is free and open source under the MIT License. It has no ads, accounts or telemetry.

Does PerfWindow keep running in the background?

No. The sensor service starts when you open PerfWindow and exits when you close it. There is no tray icon and nothing starts with Windows.

Why does PerfWindow ask for administrator approval when it starts?

CPU temperatures, clocks and power, and drive SMART data, can only be read with administrator rights. PerfWindow runs the dashboard as you and asks Windows once per launch to start its sensor service, which reads the hardware.

Can PerfWindow change my hardware settings?

No. PerfWindow only reads sensors. It doesn't overclock, undervolt, change fan curves or write to any hardware setting.

What is PawnIO and why does the installer add it?

PawnIO is a small, signed kernel driver that LibreHardwareMonitor uses to read CPU temperature, clock and power registers. The installer adds it unless a current version is already installed. Without it, everything except those CPU readings still works.

Does PerfWindow collect any data?

No. Its only connection is an anonymous update check against GitHub's public Releases API, at most once every six hours, which you can turn off in Settings. See the privacy statement.

Can PerfWindow stay out of the way?

Yes. The cards fill any window size, and in Settings you can make the window's backgrounds see-through from 100 % to 30 %. Press Ctrl+M, or click MINI in the title bar, to collapse the window into a one-line strip of live values over the top of the screen. It takes no screen space, doesn't take focus from the game or app you're in, and has its own opacity slider; the expand button brings the full window back.

Get PerfWindow

One installer adds PerfWindow, its sensor service and, when needed, PawnIO and the Visual C++ runtime. Uninstall it from Settings, Apps.
